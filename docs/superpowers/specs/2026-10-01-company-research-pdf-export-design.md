# 当前公司研究 PDF 导出设计

日期：2026-10-01

## 1. 目标

在公司研究页面为当前选中的公司增加“导出 PDF”能力。报告首先服务于个人复盘和归档，但使用稳定、正式的排版，为以后增加对外分享版本保留扩展空间。

本功能导出当前研究状态，不要求用户先创建研究快照，也不创建或修改任何研究数据。PDF 是当前数据在导出时点的只读呈现，不是新的数据来源。

## 2. 范围与边界

第一版只导出当前公司的以下内容：

1. 公司研究正文。
2. 全部研究假设。
3. 与该公司相关的全部证据及来源。
4. 内容完整性提示和报告元数据。

投资决策、交易记录、持仓、投资复盘和历史研究快照不进入本报告。第一版不提供内部版与分享版切换，不使用 AI 自动补全、总结或评价研究内容，也不把网页直接打印成 PDF。

## 3. 报告结构

### 3.1 封面

封面显示公司或标的名称、报告类型“当前公司研究报告”、研究最近更新时间、PDF 导出时间和研究状态。核心研究字段不完整时，状态显示为“研究进行中”；完整时显示为“当前研究”。封面注明“个人研究记录，不构成投资建议”。

### 3.2 核心摘要

摘要包含当前判断、投资逻辑、主要风险和判断失效条件。空字段不生成空白章节，而是在报告末尾的资料缺口中统一列出。

### 3.3 公司研究正文

正文按现有研究模型展示：

1. 业务模式。
2. 客户价值。
3. 竞争优势。
4. 长期关键假设。
5. 盈利质量。
6. 管理层与文化。
7. 仍不知道的事项。

辅助检查状态只在存在实际状态或备注时展示，不把未操作的默认检查项填满报告，也不生成虚假的完成率。

### 3.4 假设与验证

每条假设显示假设陈述、关键变量、当前状态和下次检查时间。状态使用中文标签：未验证、支持、受到挑战、结论不明确。

### 3.5 证据记录

导出与该公司关联的全部证据。每条证据显示影响方向、内容、来源名称、发生时间和来源链接；有关联假设时，同时标明对应假设。来源链接在 PDF 中保持可点击。缺少链接或来源名称时仍允许导出，并明确显示“来源未记录”，不虚构来源。

证据按发生时间优先、创建时间兜底进行倒序排列。影响方向使用支持、挑战、混合、中性四类中文标签，不仅依靠颜色表达，以保证黑白打印仍可理解。

### 3.6 资料缺口

报告末尾集中列出未填写的核心研究字段、仍未验证或结论不明确的假设，以及没有来源记录的证据数量。该部分只陈述数据状态，不给出自动评分，也不判断公司是否值得投资。

## 4. 交互设计

选中公司后，公司研究详情顶部显示“导出 PDF”按钮；未选择公司时不显示。点击后按钮进入加载状态，后端成功返回文件后触发浏览器下载。文件名格式为：

```text
公司名称-当前公司研究-YYYY-MM-DD.pdf
```

文件名中的 Windows 非法字符和控制字符必须清理。导出成功不弹出多余确认流程；失败时保留当前页面状态并显示具体错误。研究尚未完整也允许导出，不要求先保存快照。

## 5. 技术设计

### 5.1 导出接口

新增用户隔离的导出接口：

```text
GET /api/investment/research/{researchProfileId}/export
```

接口依次完成：

1. 验证当前登录用户。
2. 按 `researchProfileId` 和 `user_id` 查询研究档案。
3. 查询该研究档案的假设。
4. 按公司名称和当前用户查询证据；保留现有证据模型的公司级与假设级关联。
5. 整理成与数据库和页面解耦的报告数据结构。
6. 生成 PDF 二进制响应，设置 `application/pdf` 和安全的下载文件名。

不存在、无权访问或查询失败时不生成空白 PDF。无权访问与不存在均返回不泄露记录存在性的安全响应。

### 5.2 报告数据整理器

数据整理器是纯函数模块，负责字段映射、中文状态标签、排序、资料缺口计算和文件名清理。它不访问数据库，也不负责绘制 PDF，便于独立测试。

### 5.3 PDF 生成器

PDF 生成器只接收结构化报告数据，负责中文字体、标题层级、页边距、自动分页、页眉页脚、页码、可点击链接、长文本换行和跨页内容处理。接口层不包含版式细节。

生成器优先采用适合服务端运行、可嵌入中文字体且能稳定控制分页的 PDF 库。中文字体必须随项目提供或使用经过部署环境验证的明确字体路径，不能假设生产环境安装了某个系统字体。

## 6. 错误处理与安全

- 所有查询同时按当前用户过滤，不能只依赖前端传入的公司 ID。
- 导出是只读操作，不写入快照、更新时间或审计字段。
- 字段缺失时生成“研究进行中”的有效报告，不用占位文字伪装完整内容。
- 假设或证据为空时显示简短的“暂无记录”，不生成空表格。
- 超长链接显示可读的截断文本，但保留完整可点击目标。
- 任一数据库查询失败时终止生成并返回明确错误，不生成部分报告冒充完整报告。
- PDF 内容来自用户记录，绘制时按纯文本处理，不能解释为 HTML 或执行脚本。

## 7. 验证方案

### 7.1 单元测试

覆盖报告数据整理、状态翻译、证据排序、资料缺口、空数据处理和文件名清理。

### 7.2 接口测试

覆盖未登录、记录不存在、记录不属于当前用户、完整研究、不完整研究、无假设、无证据和数据库查询失败。验证响应类型、下载文件名和只读行为。

### 7.3 PDF 内容与视觉验证

使用包含中文、长段落、长链接、多条假设、多页证据和缺失字段的代表性样例生成 PDF。重新打开文件并提取文本，确认主要章节和数据存在；随后把每一页渲染为 PNG，人工检查：

- 中文没有方框、乱码或缺字。
- 标题、正文和表格没有重叠或裁切。
- 长链接和长证据能正确换行。
- 章节和单条记录没有出现不可读的分页断裂。
- 页眉、页脚和页码位置一致。
- 黑白打印时仍能识别证据影响方向。

只有接口测试通过不足以宣称功能完成；最终验收必须包含实际 PDF 渲染检查。

## 8. 验收标准

1. 用户可以从当前选中的公司研究直接下载 PDF，无需先创建研究快照。
2. 报告包含当前研究、全部假设、全部公司证据及其来源。
3. 投资决策、交易、持仓和复盘不混入报告。
4. 不完整研究仍可导出，并准确列出资料缺口。
5. 报告不自动生成研究结论、评分或买卖建议。
6. 其他用户无法通过修改 ID 导出不属于自己的研究。
7. 中文、多页内容、长文本和链接经过真实渲染验证，没有可见排版缺陷。
8. 导出过程不创建快照，也不修改任何现有研究数据。

## 9. 后续扩展但本次不做

- 对外分享版及字段隐藏开关。
- 导出历史研究版本。
- 合并投资决策、交易记录或复盘。
- 自定义封面、品牌标识和报告模板。
- AI 摘要、自动评价、估值或投资建议。
- 定时生成、批量导出或邮件发送。
