# 日志与方法论轻量排版设计

## 目标与范围

为投资日志、投资方法论、认知日志和认知方法论提供统一的常用正文排版能力。首期覆盖投资日志正文、投资方法论规则内容、认知日志正文，以及认知方法论的核心原则、适用情境、判断依据、行动规则、例外与反例。

研究资料正文可在后续直接复用本组件，但本次不改。公司研究、行业研究、投资决策等结构化表单，以及交易备注、目标进展等短文本继续使用普通输入框。

## 方案

保留现有文本字段、API 和数据库结构，内容仍以纯字符串保存。编辑态继续采用普通多行文本框，在上方增加极简快捷工具栏；阅读态将受支持的轻量标记安全转换为 React 元素。现有纯文本无需迁移，并继续按原意显示。

不引入完整富文本编辑器，不保存 HTML，不支持任意字体、字号、任意颜色、下划线、对齐、图片、表格或附件。

## 支持的格式

工具栏只提供五项常用操作：

- 粗体：`**重点**`
- 小标题：`## 小标题`
- 无序列表：`- 条目`
- 引用：`> 引用或警示`
- 固定强调色：使用单一、受控的轻量标记，由阅读组件显示为统一强调色

换行属于基础能力而非工具栏按钮。编辑时一次回车在阅读态换一行，空一行形成新段落；不要求用户添加 Markdown 的行尾双空格或 HTML 标签。列表和引用中的连续内容保持对应块级结构。

## 编辑交互

点击粗体或强调时，如果已有选区，则包裹选中文字；没有选区时插入可直接替换的示例文字并选中它。点击小标题、列表或引用时，对当前行或所选多行逐行添加对应前缀；再次点击同类操作可移除前缀。操作后焦点回到文本框，并尽量保持合理选区。

组件作为受控表单输入使用，接收字符串值并通过 `onChange` 返回新字符串，以便直接嵌入现有 Ant Design `Form.Item`。不改变保存、校验和请求流程。

## 阅读与安全

阅读组件只解析上述白名单格式，不使用 `dangerouslySetInnerHTML`，因此正文中的 HTML 按普通文字显示。未闭合或不合法的标记按原文显示，不阻止页面渲染。链接、图片、代码块及其他 Markdown 语法本次不解析。

列表摘要和搜索仍基于原始字符串。为避免摘要出现大量标记，可在列表摘要展示前仅移除本功能支持的格式符号；搜索继续匹配实际文字内容。

## 组件边界

实现两个共享组件和一个纯文本转换模块：编辑组件只负责工具栏、文本框和选区操作；阅读组件只负责安全渲染；纯函数负责格式标记的增删和解析，使页面接入保持简单，并便于单元测试。

四个页面只替换对应正文输入与阅读展示。认知方法论的五个正文型字段共享同一套组件和规则。

## 验证

单元测试覆盖粗体、固定强调、小标题、列表、引用、一次回车换行、空行分段、非法标记回退和 HTML 不执行。组件测试覆盖有选区与无选区的按钮操作、受控值更新和焦点恢复。页面测试确认四个页面均接入共享组件，现有新增和编辑流程不变。最后执行相关测试、类型检查、代码检查和生产构建。
