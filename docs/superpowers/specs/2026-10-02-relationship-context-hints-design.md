# 人际关系近况填写提示设计

## 目标

在联系人编辑弹窗的“家庭近况”和“工作近况”字段下方增加常驻填写提示，帮助用户记录以后联系时真正有用的事实。

## 设计

- 沿用现有 `family_context` 与 `work_context` 文本字段，不新增数据库字段或接口参数。
- 使用 Ant Design `Form.Item` 的 `extra` 展示说明，使用户输入后仍能看到提示。
- 家庭提示覆盖孩子数量与年龄阶段、配偶特征或近况、父母情况和家庭近期变化。
- 工作提示覆盖行业与公司、岗位职责、当前项目、职业变化、工作压力和近期关注。
- 提示仅用于启发填写，不要求用户收集或记录所有信息，也不覆盖已有内容。

## 验证

组件测试断言两段提示可见；随后执行联系人组件测试、ESLint 和生产构建。
