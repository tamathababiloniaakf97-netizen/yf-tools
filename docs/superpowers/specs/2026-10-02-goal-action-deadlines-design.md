# 年度目标行动截止日期设计

## 目标

为年度目标的下一步行动增加可修改的截止日期，使首页行动状态和全站到期提醒有明确时间依据。

## 行为

- 目标编辑和阶段进展更新均可维护行动截止日期。
- 目标卡片显示当前行动及截止日期，进展历史保留每次更新时的行动期限。
- 首页仍汇总所有有效行动：按截止日期显示已过期、今日、已安排；历史无日期目标继续标记为无日期。
- 小铃铛只显示截止日在今天或已经逾期的进行中目标，未来及无日期行动不提醒。
- 迁移不为历史目标猜测日期；用户下次编辑或更新进展时补录。

## 数据

`goals` 与 `goal_progress_updates` 分别增加可空的 `next_action_due_at date`。`save_goal_progress` 同时保存历史快照并同步目标当前值。
