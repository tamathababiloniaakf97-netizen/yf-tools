# 人生工作台一键启动脚本设计

## 目标

在项目部署前提供一个可直接双击的 Windows 启动入口，让用户无需打开终端或输入命令即可启动并打开人生工作台。

## 文件与入口

- 在项目根目录创建 `一键启动人生工作台.cmd`，作为用户唯一需要双击的入口。
- 在 `scripts/start-life-workbench.ps1` 中实现服务检测、后台启动、等待和打开浏览器，避免在批处理文件中堆积复杂逻辑。
- 启动地址固定为 `http://localhost:3000/investment`。

## 启动流程

1. 脚本以自身所在目录作为项目目录，不依赖用户从哪个文件夹双击。
2. 先请求正式网站地址；若已可访问，直接使用 Windows 默认浏览器打开。
3. 若网站不可访问，则在项目目录后台执行 `npm run dev -- --port 3000`，不保留可见终端窗口。
4. 最多等待 30 秒，每秒检查一次网站是否可访问。
5. 网站可访问后自动打开投资概览；超时则显示中文错误信息，并提示检查 Node.js、依赖和端口占用。

## 边界与安全

- 不重复启动已运行的开发服务。
- 不结束已有进程，不抢占或清理端口。
- 不设置开机启动，不写注册表，不创建系统服务，不修改执行策略的持久配置。
- 本脚本只用于本机开发阶段；正式部署后应使用固定网址替代。

## 验收标准

1. 网站未启动时，双击入口可后台启动服务并打开投资概览。
2. 网站已启动时，双击入口直接打开页面且不创建第二个服务进程。
3. 从任意当前目录调用脚本都能定位项目目录。
4. 启动失败或超时会显示可理解的中文错误，而不是静默结束。
