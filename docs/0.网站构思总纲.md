### 六、成本计算引擎（cost-engine.ts）

供页面三使用的核心算法，对外暴露两个函数：

```
// 计算某个标的的当前持仓成本
function calculateCostBasis(userId, tickerId): {
  costPerShare: number,    // 每股成本 USD
  totalCost: number,       // 成本总额 USD
  totalShares: number,     // 当前持仓数量
  isNegativeCost: boolean  // 是否负成本
}

// 计算账户汇总
function calculateAccountSummary(userId): {
  totalAssets: number,     // 总资产 = 持仓市值 + 现金余额
  cashBalance: number,     // 现金余额
  totalInvested: number,   // 总投入
  totalPnL: number,        // 总盈亏
  positions: Position[]    // 每个标的的持仓详情
}
```

算法规则：
```
持仓成本 = (累计买入USD - 累计卖出USD - 累计分红USD - 累计期权USD) ÷ 当前持仓数量
现金余额 = 累计入金 - 累计出金 + 累计卖出收入 - 累计买入支出 + 累计分红 + 累计期权净收益
总资产 = 持仓市值 + 现金余额
总盈亏 = 总资产 - 总投入（总投入 = 累计入金 - 累计出金）
```

### 七、新增页面的开发规范

当后续新增页面一、二、四时，遵循以下步骤：

1. 在 `src/app/` 下新建对应的路由文件夹（如 `/blog`）
2. 如果新页面需要新数据表，在 `schema.sql` 中添加，**不改已有表**
3. 导航栏组件 `Navbar.tsx` 中已有的菜单项只需取消灰色状态
4. 共享组件（AuthGuard 登录保护）所有页面复用
5. 新页面的需求文档放在 `Code/TOOLS/` 对应目录中
