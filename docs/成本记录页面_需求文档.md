# 远峯投资策略工作台 — 成本记录页面需求文档

> 本文档写给 AI 开发使用，描述的每个功能都会直接实现。

---

## 一、概述

成本记录页面是整个工作台最基础、最核心的功能。用户在此页面**手动记录每一笔交易**，系统自动算出**每个标的的持仓成本**，并展示**总资产、总市值、持仓净值**等汇总数据。

### 核心目标
- 记录交易流水（买/卖/分红/期权权利金）
- 自动计算每个标的的**持仓成本**（终身成本法，清仓不重置）
- 展示账户总览：总资产、总市值、总盈亏、持仓净值
- 净值与标普500对比（展示跑赢还是跑输）

## 三、支持的标的类型

用户可添加和管理以下 5 类标的：

| 类型 | 示例 | 原始币种 | 说明 |
|------|------|---------|------|
| A股 | 贵州茅台、招商银行 | CNY | 在上海/深圳交易所 |

| 期权 | SPY Put/Call | USD | 期权合约 |

## 四、交易记录类型

用户可录入以下 5 类交易：

### 1. 买入（Buy）
- 日期
- 标的（从已添加的标的中选择）
- 数量
- 单价（原始币种）
- 总金额（原始币种，系统自动算）
- 备注（可选）

### 2. 卖出（Sell）
- 日期
- 标的（从已添加的标的中选择）
- 数量
- 单价（原始币种）
- 总金额（原始币种，系统自动算）
- 备注（可选）

### 3. 分红（Dividend）
- 日期
- 标的（从已添加的标的中选择）
- 分红金额（原始币种）
- 备注（可选）

### 4. 期权收益（Option Income）
期权产生的所有收益都计入降低持仓成本，包括两类：

#### 4a. 卖出期权获得权利金（Sell Put / Sell Call）
- 日期
- 关联标的（这笔收益用来降低哪个标的的成本）
- 期权类型（Sell Put / Sell Call）
- 权利金收入（USD）
- 到期日
- 备注（可选）

#### 4b. 买入期权平仓价差收益（Buy Put / Buy Call Spread）
- 日期
- 关联标的
- 期权类型（Buy Put / Buy Call）
- 买入权利金支出（USD）
- 卖出平仓收入（USD）
- 净收益（USD，系统自动算：卖出收入 - 买入支出）
- 备注（可选）

> **期权收益对现金的影响**：4a（卖出权利金）和4b（买入平差价差净收益）都会增加现金余额。现金余额公式中的"累计期权净收益"包含这两类。

### 5. 入金 / 出金（Deposit / Withdraw）
记录资金转入和转出账户，用于计算**现金余额**和**净值份额**。

#### 5a. 入金（Deposit）
- 日期
- 入金金额（USD）
- 资金来源（如：银行卡、工资等，可选）
- 备注（可选）

#### 5b. 出金（Withdraw）
- 日期
- 出金金额（USD）
- 去向（可选）
- 备注（可选）

## 五、核心算法：终身成本法

这是整个系统的核心逻辑，必须实现：

### 成本计算公式

```
当前持仓成本（USD）= (累计买入总支出 - 累计卖出总收入 - 累计分红 - 累计期权收益) ÷ 当前持仓数量
```

### 关键规则
1. **所有金额统一折算为 USD** 后进行计算
2. **终身制不清零**：即使清仓了（持仓数量 = 0），成本池（累计买入-累计卖出-分红-期权收益）保持不变。未来再次买入时，继续累加。
3. **当持仓数量为 0 时**：如果成本池为负数（即卖出+分红+期权收益已经覆盖了所有买入成本），显示"负成本"状态。
4. **成本可以为负**：当累计收入超过累计支出时，持仓成本显示为负数，代表这部分持仓已经是"零成本"并且还赚了。

### 示例

```
买入 100 股 SPY @ 400 → 累计买入 = 40,000
卖出 50 股 SPY @ 450 → 累计卖出 = 22,500
分红收入 = 500
Sell Put 权利金收入 = 300
Buy Call 价差净收益（买入300支出 → 卖出800收入）= 500

当前持仓 50 股
持仓成本 = (40,000 - 22,500 - 500 - 300 - 500) ÷ 50
          = 16,200 ÷ 50 = 324 USD/股
```

## 六、页面布局

### 顶部：账户总览栏（横向卡片）

展示全账户的核心指标：

| 指标 | 说明 |
|------|------|
| 总资产 | **持仓市值 + 现金余额**（USD） |
| 现金余额 | 累计入金 - 累计出金 + 累计卖出收入 - 累计买入支出 + 累计分红 + 累计期权净收益 |
| 持仓市值 | 各标的最新价 × 持仓数量之和（USD） |
| 总投入 | 累计入金 - 累计出金（即净投入资金） |
| 总盈亏 | 总资产 - 总投入 |
| 盈亏比例 | 总盈亏 ÷ 总投入 × 100%（当总投入≤0时显示"—"） |

> **资金流转逻辑**：买入→现金减少，卖出→现金增加，分红→现金增加，期权收益（卖出权利金+买入平差价差）→现金增加，入金→现金增加，出金→现金减少。

### 中间：持仓列表（表格）

每一行代表一个标的：

| 列 | 说明 |
|----|------|
| 标的名称 | 用户自定义名称 + 代码（如 SPY） |
| 类型 | 美股/港股/A股/期权/加密 |
| 持仓数量 | 当前持有的股数/张数 |
| 持仓成本（USD） | 按终身成本法计算 |
| 现价（USD） | 最新价（初期可手动输入，后期接入行情） |
| 市值（USD） | 持仓数量 × 现价 |
| 盈亏（USD） | (现价 - 持仓成本) × 持仓数量（等于持仓市值 - 持仓成本 × 数量） |
| 盈亏比例 | 持仓成本 > 0 时：盈亏 ÷ (持仓成本 × 数量) × 100%；持仓成本 ≤ 0 时：显示"**负成本**" |
| 仓位占比 | 该标市值 ÷ 总资产 × 100% |
| 操作 | 点击可查看该标的的历史流水 |

### 下方：净值走势图

- X轴：时间
- Y轴：净值
- 两条曲线：
  - **我的净值曲线**（实线）—— 基于净值化算法
  - **标普500曲线**（虚线）—— 同一时间区间的 SPY 表现
- 显示：累计收益率、年化收益率、最大回撤

### 底部：交易流水列表

按时间倒序展示所有交易记录，每条显示：
- 日期、类型（买入/卖出/分红/权利金）、标的、数量、单价、金额（USD）

支持按标的筛选、按类型筛选、按日期范围筛选。

## 八、净值化算法（用于净值曲线）

参考公募基金的净值计算方式：

```
总资产 = 持仓市值 + 现金余额

初始净值 = 1.0000

每日净值 = 当前总资产 ÷ 当前总份额

入金时：新份额 = 入金额 ÷ 当日净值
出金时：减少份额 = 出金额 ÷ 当日净值
```

这样可以排除"中途追加本金"对收益率的影响，真实反映投资能力。

## 九、标普500基准数据来源

### 实现方案
使用 **yfinance** 库自动获取 SPY（标普500 ETF）的历史日线数据。

### 工作流程
1. 用户打开净值曲线页面时
2. 系统获取用户第一条交易记录的日期（基准起点）
3. 调用 yfinance 拉取同一时间段的 SPY 日线数据
4. 将 SPY 的起始净值归一化为 1.0000，与用户净值曲线绘制在同一张图上
5. 两条曲线起点相同，直观对比跑赢还是跑输

### 代码示意
```
spy_data = yfinance.download("SPY", start=用户首笔交易日期, end=今天)
spy_nav = spy_data['Close'] / spy_data['Close'].iloc[0]  # 归一化到1.0
```

### 注意事项
- yfinance 免费使用，无需 API Key
- 如果网络请求失败，曲线图仅显示用户净值线，并提示"基准数据暂时无法获取"
- 后期可改为从 Supabase 本地存储的 SPY 数据读取，减少外部依赖

## 十二、附录：用户操作流程

### 新用户第一次使用

```
1. 管理员在后台添加用户邮箱
2. 用户收到邀请链接，设置密码
3. 登录 → 进入成本记录页面（空的）
4. 点击"添加标的" → 输入标的名称、代码、类型
5. 点击"录入交易" → 选择标的、填写买入记录
6. 系统自动计算并刷新持仓数据
```

### 日常使用

```
1. 打开网页 → 登录
2. 看到持仓总览（总资产、盈亏）
3. 看持仓列表，检查每个标的的成本和盈亏
4. 有交易时，点击"录入交易"记录
5. 查看净值曲线，对比标普500
```
